# InstagramStory

قالبين ستوري 1080×1920: «مشروع جديد» و«متاح لمشاريع».

- اترك 120px فوق و200px تحت فاضية من النص: واجهة إنستقرام تغطيها.
- «مشروع جديد»: لقطة من التصميم + عنوان + خط ذهبي قصير (العنصر الذهبي).
- «متاح لمشاريع»: الرمز «ن» بالنص، وسطر التواصل بالذهبي. انشره مرة كل أسبوعين.
- الريلز (تايم لابس، قبل/بعد) تستخدم نفس الغلاف: أول فريم = قالب «مشروع جديد».
