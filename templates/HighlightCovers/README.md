# HighlightCovers

أربع أغلفة هايلايتس 1080×1080 بنفس سماكة خط الشعار، وكل غلاف فيه عنصر ذهبي واحد.

| الملف | اسم الهايلايت |
| --- | --- |
| `nori-highlight-work.svg` | الأعمال |
| `nori-highlight-before-after.svg` | قبل وبعد |
| `nori-highlight-services.svg` | الخدمات |
| `nori-highlight-contact.svg` | تواصل |

إنستقرام يقص الغلاف دائرة، فكل الرسم داخل دائرة قطرها 640px بالنص. ارفع نسخة الـ PNG من الملف المضغوط.
