# ProfileGrid

شكل البروفايل كامل: الصورة، البايو، الهايلايتس، والشبكة. كل صف من 3 بوستات = مشروع واحد.

- إنستقرام يعرض أحدث بوست يسار الصف الأول (حسب اتجاه التطبيق)، فانشر بوستات المشروع الثلاثة ورا بعض بنفس اليوم أو بنفس الأسبوع.
- نوّع الصفوف: غلاف + شريحتين، أو قبل/بعد + شريحة + غلاف، عشان الشبكة ما تصير مملة.
- كل الخلفيات `#0E0E0E` أو `#1C1C1C`. الذهبي يطلع مرة وحدة بكل بوست.
- الشبكة الحالية بالبروفايل (منذ 2025) تعرض البوستات بنسبة 3:4 طولي؛ لو صممت 1080×1350 حط المحتوى المهم بالمربع الوسط 1080×1080.
