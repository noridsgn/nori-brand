# InstagramPost

ثلاث قوالب بوست مربع 1080×1080: غلاف المشروع، شريحة داخلية، وقبل/بعد.

## الشبكة

- هامش آمن 80px (`space-10`) من كل جهة. لا نص ولا شعار خارجه.
- العلامة المائية فوق يسار، ارتفاع 30px. رقم الشريحة فوق يمين `social-meta-en`.
- النص العربي يمين، والسطر الإنجليزي تحته بلون `nori-ash`.

## القوالب

1. **غلاف المشروع:** التصميم بالثلثين الفوق، وتحته ليبل الكونسبت + العنوان `social-title-ar` + سطر إنجليزي: البراند ونوع الحملة.
2. **شريحة داخلية:** التصميم داخل إطار بهامش 80px، وسطر شرح واحد تحت `social-body-ar`.
3. **قبل / بعد:** نصين، والخط الذهبي 4px بالنص هو العنصر الذهبي الوحيد. «قبل» يمين و«بعد» يسار (اتجاه القراءة العربي).

## بالفوتوشوب

سوّ ملف 1080×1080 بـ guides على 80px و540px، واحفظه كـ template. الخلفية `#0E0E0E` دايماً، مو أسود صافي.
