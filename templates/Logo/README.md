# Logo

شعار نوري له أربع نسخ: المكدّس (الأساسي)، الأفقي، الرمز «ن»، والعلامة المائية NORI.

## النسخ ومتى تستخدمها

| النسخة | متى | أصغر مقاس |
| --- | --- | --- |
| مكدّس `nori-logo-stacked-*` | غلاف البورتفوليو، الكرت، أول بوست، الموقع | عرض 120px رقمي / 30mm طباعة |
| أفقي `nori-logo-horizontal-*` | رأس الصفحات، توقيع الإيميل، شرائح الـ PDF | عرض 160px / 40mm |
| الرمز `nori-mark-*` | صورة البروفايل، الأيقونة، الختم الصغير | 32px |
| العلامة المائية `nori-watermark-*` | زاوية كل تصميم تنشره (فوق يسار، داخل هامش 80px) | ارتفاع 24–30px على 1080 |

## القواعد

- **المساحة الفاضية:** حول الشعار مسافة تساوي ارتفاع حرف N في كلمة NORI من كل جهة.
- **على الأسود:** النسخة `on-dark` (عاجي + ذهبي #C9A45C). **على الفاتح:** `on-light` (أسود + ذهبي غامق #9A7633).
- **النقطة الذهبية لا تتغير:** لا تلوّنها بلون ثاني، ولا تشيلها.
- **فوق الصور:** فقط إذا الصورة غامقة وهادية، واستخدم on-dark.

## ممنوع

- تمدد الشعار أو تضغطه أو تميّله.
- تكتب «نوري» بخط ثاني بدل الحروف المرسومة.
- تحط ظل أو توهج أو تدرج على الشعار.
- تحط الشعار على خلفية ملونة أو مزدحمة.
- تستخدم أبيض صافي #FFFFFF بدل العاجي.
