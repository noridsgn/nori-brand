# BusinessCard

كرت عمل 85×55mm بوجهين، أسود مطفي (Matte) والذهبي طباعة فويل لو الميزانية تسمح.

- الوجه: الشعار المكدّس بالنص، بس.
- الظهر: الرمز «ن»، الاسم والتخصص بالعربي والإنجليزي، وسطر تواصل واحد.
- اليوزر والرقم والدومين بالقالب أمثلة: غيّرهم لحساباتك الحقيقية قبل الطباعة.
- ملف الطباعة: 91×61mm (3mm نزف من كل جهة)، CMYK، 300dpi. الأسود الغني للطباعة: C60 M40 Y40 K100.
- وجود QR يودي للبورتفوليو اختياري، بالظهر تحت يسار.
