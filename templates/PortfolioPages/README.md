# PortfolioPages

قالب ملف البورتفوليو PDF: شرائح أفقية 1920×1080.

## الترتيب

1. الغلاف: الشعار الأفقي، «Selected Work» و«أعمال مختارة»، والتخصص.
2. نبذة بسطرين + الخدمات.
3. المشاريع: صفحتين لكل مشروع. الأولى: التصميم الرئيسي يسار، والنص يمين (رقم، عنوان، الفكرة، المخرجات، ليبل الكونسبت). الثانية: البوستات والستوريز على موك أب جوال.
4. شهادات العملاء.
5. تواصل: واتساب، إنستقرام، الموقع.

## القواعد

- هامش 80px للصور و120px للنص.
- عمود النص عرضه 560px بالكثير.
- صدّر PDF بجودة 150dpi وحجم أقل من 10MB.
