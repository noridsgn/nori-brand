# ConceptLabel

ليبل إلزامي على أي تصميم لبراند حقيقي ما اشتغلت معه رسمياً، عشان ما يفهم أحد إنهم عملاؤك.

- مكانه: أسفل يمين البوست الأول من كل مشروع، وأول صفحة للمشروع بالـ PDF.
- الشكل: إطار ذهبي 2px، زوايا `radius-pill`، نص ذهبي: «CONCEPT · غير رسمي».
- المقاس على 1080: الارتفاع حوالي 50px.
- هو العنصر الذهبي الوحيد بالبوست: لا تضيف ذهبي ثاني معه.
- لو المشروع لعميل حقيقي، شيله واكتب اسم العميل بدال (بعد موافقته).
