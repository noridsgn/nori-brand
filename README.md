# NORI brand kit

Source files for the «نوري | NORI» identity, kept here so every content session (posts, reels) pulls the same assets.

| Folder | What |
| --- | --- |
| `BRAND.md` | Brand book: idea, colours, type, rules, voice (Arabic) |
| `logos/` | Stacked, horizontal, mark «ن», avatar, watermark — on-dark and on-light |
| `highlights/` | Instagram highlight covers |
| `fonts/` | IBM Plex Sans Arabic (all weights), Inter, Inter Display |
| `tokens/tokens.json` | Colour, type, spacing and radius tokens |
| `templates/` | HTML templates for posts, stories, profile grid, card, portfolio pages |

## Updates since the brand book

- **Instagram post size is now 1080×1440 (3:4)**, not 1080×1080. Safe margin stays 80px.
- `logos/nori-mark-on-light.svg` and `logos/nori-watermark-dark.svg` were generated from the on-dark files with the on-light colours (#0E0E0E + #9A7633).

## Core rules (short)

- Background `#0E0E0E`, text ivory `#F2F0EB`, secondary `#8A8A8A`, gold `#C9A45C` (dark gold `#9A7633` on light).
- **One gold element per design.**
- Arabic: IBM Plex Sans Arabic. English/numbers: Inter.
- Watermark top-left, 30px high, on every post.
