أضف للطلب السابق (أو الصقه بآخر البرومبت):

1. المعاينة التفاعلية
• اعرض واجهة الهاتف كاملة داخل Claude Artifact بمقاس 393×852. ينبغي أن تتطابق المحاذاة والخطوط والألوان وأبعاد البطاقات والأيقونات مع النسخة المصدّرة، وألا تظهر أدوات التصدير داخل إطار الهاتف.

2. أدوات التصدير
• Copy SVG: ينسخ الكود الكامل إلى الحافظة.
• Download SVG: ينزّل ملفاً مستقلاً باسم mobile-home-screen.svg.
• Show SVG Code: يعرض كود SVG كاملاً دون اختصار داخل مساحة قابلة للتحديد والنسخ.
• هذه الأزرار تعمل فعلياً، وتوضع خارج إطار شاشة الهاتف.

3. تنظيم طبقات Figma
• أنشئ مجموعات منفصلة بأسماء Header-01 وFloating-Card-02 وSearch-03 وServices-04 وWeekly-Offers-05 وBottom-Navigation-06.
• أبقِ الأشكال والأيقونات والنصوص منفصلة قدر الإمكان، مع ترتيب طبقات منطقي يسهل تحريره بعد الاستيراد.

4. سلامة ملف SVG
• العنصر الجذر بعرض 393 وارتفاع 852، وviewBox مطابق.
• كل العناصر ضمن حدود التصميم.
• لا صور PNG أو JPG، ولا Base64 أو Canvas أو foreignObject.
• لا تعتمد على روابط CSS أو ملفات خطوط خارجية لتفسير الأشكال.
• افحص اتجاه النص العربي والأرقام والنسب، واختبر الملف عند فتحه مستقلاً.

5. بوابة الجودة
• راجع Visual Hierarchy وRTL Alignment وArabic Typography وColor Contrast وSpacing وPixel Alignment وSVG Structure وFigma Import Compatibility.
• لا تعلن اكتمال التنفيذ إلا بعد تقديم واجهة المعاينة وملف SVG كامل صالح للاستخدام.
