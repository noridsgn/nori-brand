# Experiment: "Pause 1.0 Flash" UI-demo motion (2 Nov 2026)

NORI asked to test the motion style of the Pause 1.0 Flash launch film (whatships.com/videos/pause-1-flash, by @Truffievfx) on Reel A's voice. NOT scheduled; the approved Reel A (cinematic dark style) stays in Metricool.

Style taken (idea, not copied assets): warm ivory background with big soft blurred colour blobs (here Loomi lime + NORI gold + soft blue) and faint concentric rings; one hero UI element in the centre (a prompt bar "نوري 1.0" with a gold send button); the voice is typed into the bar as the prompt; rounded white-bordered thumbnail cards with soft shadows float in with a spring and drift; a hand cursor drags a card into the bar and presses send; results pop in above the bar; chips row (البايو / الصورة / الهايلايتس) lights up per check; ends on the NORI logo (on-light).

Render: `node render4.js full 36.05` then mux with `../src/voice-clean.wav` (same ffmpeg line as src/README.md).
