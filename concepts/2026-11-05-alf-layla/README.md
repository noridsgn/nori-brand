# ألف ليلة وليلة · نموذج أولي (5 نوفمبر 2026)

مفهوم غير رسمي للعرض فقط، مو تابع لمطعم ألف ليلة وليلة.

- 10 سلايدات 1080×1440 بنفس طريقة عرض مشرف (alf-01 … alf-10).
- الرمز: باب (قوس) + نجمة (الليل) + شمس طالعة من تحت (يفتح 4 الفجر).
- الألوان: أحمر عنابي #9E2A22، زعفراني #E2A53A، كريمي #F3EADB، فحمي #1B1714.
- الخطوط: Aref Ruqaa للشعار، Readex Pro للنصوص (مو IBM Plex، محجوز لهوية نوري).
- الشعار مبدئي؛ نوري يصمم النهائي بالفوتوشوب. الموكابات رسومات توضيحية.
- الإعادة: `npm i @fontsource/aref-ruqaa @fontsource/readex-pro @fontsource/inter` جنب slides.html، وبعدين `node render.js` (يطلع بمجلد out/).
