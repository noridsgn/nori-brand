# بروستد الشام · نموذج أولي (5 نوفمبر 2026)

مفهوم غير رسمي للعرض فقط، مو تابع لبروستد الشام. للتواصل الخاص مع صاحب المطعم قبل أي نشر.

- 5 سلايدات 1080×1440: الغلاف، الرمز والألوان، البوكس، التطبيقات والريلز، الختام.
- الرمز: نفس فكرة الديك بشكل هندسي أنظف، سطر نص واحد بدل 3.
- «الأبلق»: خطوط سودا وبيضا (حجر الشام) توقيع البراند.
- الألوان: أحمر #D7261E، فحمي #1E1A17، ذهبي #F2B53A، كريمي #FFF4E2.
- الخطوط: Lalezar للشعار والعناوين، Baloo Bhaijaan 2 للنصوص.
- الإعادة: `npm i @fontsource/lalezar @fontsource/baloo-bhaijaan-2 @fontsource/inter` ثم `node render.js`.
