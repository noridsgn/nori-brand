# ملفات PSD · بروستد الشام v4

طلب نوري (r15، 9 نوفمبر 2026): ملف المشروع كامل PSD عشان يعدّل بنفسه.

- `broasted-02.psd` لين `broasted-10.psd`: كل سلايد ملف، 1080×1440، بطبقات منفصلة: الخلفية، والرقم، والكيكر، والعنوان، والنص، والرسمة أو الموكاب، والتشويق تحت. الطبقات مسمّاة بأول كلمات النص اللي فيها.
- الطبقات بكسل (raster)، مو نص يتعدّل بالكيبورد. لو تبي تغيّر كلمة، اكتبها بطبقة نص جديدة بنفس الخط:
  - العناوين: Kufam ExtraBold 800، 82px
  - النصوص والتشويق: Baloo Bhaijaan 2 (400 و600)
  - الأرقام والكلمات الإنجليزية: Inter 500
- `broasted-logo.svg`: الشعار فكتور (العرف بطبقة والواو بطبقة). اسحبه بـ Photoshop كـ Smart Object لو تبي تكبّره بدون ما يخرب.
- الألوان: أحمر #C8261D، فحمي #1C1816، ياسمين #F6EBDA، والذهبي #E9B04A للعين بس.
- المصدر الأصلي (HTML) بـ `../slides.tpl.html`، والصور النهائية `../broasted-*.png`. تأكدنا إن كل PSD لما يتسطّح يطلع نفس الصورة بالضبط.
