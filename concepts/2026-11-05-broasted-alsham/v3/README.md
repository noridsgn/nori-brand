# بروستد الشام · v3 · كونسبت الثلاثاء 10 نوفمبر 2026

مفهوم غير رسمي للعرض فقط، مو تابع لبروستد الشام. نوري موافق على نشره (6 نوفمبر).

**v3 مبنية على شعار نوري نفسه** (`../logo/chickn.png`): حرف الواو بالكوفي المربع + عرف ومنقار = ديك. المربع الصغير بنص الواو هو عين الديك.
10 سلايدات 1080×1440 بنفس ترتيب كونسبت مشرف (الغلاف، الفكرة، الشبكة، الألوان والخط، الهايلايت، البوكس، التغليف، التطبيق، الواجهة، الختام).

- الشعار: انرسم vector من chickn.png (جسم الواو مربعات دقيقة، والعرف والمنقار potrace) → `paths.json`. إذا نوري عدّل الـ PSD، نعيد الاستخراج.
- الألوان: أحمر #D7261E، فحمي #1E1A17، ذهبي #F2B53A، ياسمين #FFF4E2. «الأبلق» (خطوط سودا وبيضا) باقي توقيع.
- الخطوط: Kufam (كوفي يمشي مع مربعات الشعار) للعناوين، Baloo Bhaijaan 2 للنصوص.
- الختام بدون دايركت ولا سعر (القاعدة G): سؤال للكومنت بس.
- الموكابات رسومات توضيحية مو صور حقيقية.
- الإعادة: `npm i @fontsource/kufam @fontsource/baloo-bhaijaan-2 @fontsource/inter` ثم `python3 build.py && node render.js` (يطلع بـ out/).
